# MicroAIStudios-DAO organization standards

This repository publishes the organization profile and default community-health files used across MicroAI Studios DAO repositories.

- [`profile/README.md`](profile/README.md) is the public organization landing page.
- [`docs/PORTFOLIO.md`](docs/PORTFOLIO.md) defines the canonical product architecture.
- [`docs/CONSOLIDATION.md`](docs/CONSOLIDATION.md) records repository consolidation decisions.
- [`docs/BRANCH_POLICY.md`](docs/BRANCH_POLICY.md) defines branch lifecycle and deletion safeguards.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`SECURITY.md`](SECURITY.md) provide organization defaults.

Product claims belong in the repository that implements them. Portfolio documents distinguish current implementation from target architecture and commercial packaging.
